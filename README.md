# Journal Figure Polish

一个用于精修既有学术期刊配图的 Codex skill。核心判断是：期刊图属于论文论证，不是网页或 PPT 展示页；视觉层次应来自物理对象、数据关系和面板逻辑。

技能保留复杂构图与信息密度，聚焦字体、坐标轴、图例、线条、箭头、色彩、局部对齐和图面质感。`references/negative-example.md` 收录一张反面教材及其原始绘图脚本，供识别网页式页眉、信息卡和页脚等版式问题。

## 安装

将本仓库目录复制到 `~/.codex/skills/journal-figure-polish`，然后在 Codex 中使用 `journal-figure-polish`。

## 内容

- `SKILL.md`：技能指令
- `references/negative-example.md`：反面教材说明
- `assets/negative-example/`：示例图与绘图脚本
